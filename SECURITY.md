# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead: [report a vulnerability](https://github.com/Cartooli/sunshine-bot/security/advisories/new). Include:

- what the issue is and where it lives (file, command or page)
- steps to reproduce, or a minimal example
- the impact you expect

We aim to acknowledge reports within 5 business days and will agree a fix and disclosure timeline with you.

## Scope

In scope: the CLI and published npm package, the sample workflow, and anything that could leak a Slack webhook or other secret, run unexpected code, or write outside the target repo. Out of scope: Slack, GitHub and npm themselves.

## Supported versions

Only the latest commit on the default branch is maintained.
